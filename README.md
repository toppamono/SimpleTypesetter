# Simple Typesetter

スマートフォン／タブレットを中心に使う、シンプルで軽量な日本語組版ツールです。

## 設計原則

- どこまで進めても、シンプルで軽い運用を優先する
- Canvaのような総合デザインアプリではなく、組版専用の小さな道具にする
- 紙面、文字枠、画像枠、mm単位のX/Y/W/H、整列、ルビ、段組、表、日本語組版を中心にする
- 重いフレームワークや不要な依存関係を増やさない
- 当面はビルド不要の単一HTMLで運用する

## 現在の基準版

Simple Typesetter Mobile v0.12

- 最新版: `index.html`
- 移行時点の保存版: `prototypes/v0.12.html`
